## The line

> Day 47 behind the dryer. The lint is friendly. Tell my pair I never stopped believing in laundry.

## How it works

`main.ts` (Node 22 stdlib only) reads `line.txt`, validates it is a single line of 1–120 characters, and writes it to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` first, then `MAKEFUN_BOT_DIR`, then a local fallback).

Run it with:

```sh
node main.ts
```
